# 键盘布局与自定义键码

## 物理布局（3 行，含屏幕下方一排）
正面图（1714x1160）测量：屏幕暗区 bbox x=463..1248 (w=785)、y=135..525；其下第 1 排 11 个键（F1..F10 + DEL）中心映射到 320 屏坐标，键 4~8 中心 ≈ **49.3 / 105.6 / 162.2 / 216.5 / 274.8**。

## 关键：数字键 1~0 实为 F1~F10（自定义 keycode）
`/usr/share/keymaps/tca8418_keypad_m5stack_keymap.map` 是 loadkeys（console）格式，只映射标点。对应关系：

| 2 | 27 | @ |

| 4 | 40 | $ |

| 6 | 43 | ^ |

其余标点也在该文件：69=` 70=_ 71=- 72=+ 73== 74=[ 75=] 76={ 77=} 79=; 80=: 81=' 82=" 83=< 85=> 86=\ 89=| 90=, 91=. 92=/ 93=?

**读键盘时必须把这个自定义键码表加进映射**（不要假设标准 evdev 数字码 2..11，标准可留作兜底）。字母/数字/方向键的物理位置与标准 KEY_A..Z 等**尚未逐键物理实测**，只验证过上述标点键码。

## 方向键
屏幕下方/字母区用于方向的是 4 个键：**Z=左、X=下、C=右、F=上**（实心三角方向语义）。硬件没有独立方向键，所有导航都用它们。
- 解析按键事件：24 字节 `struct 'llHHi'`（timeval 长×2 + type u16 + code u16 + value i32），取 `type==1 (EV_KEY) && value==1/2`。

## 底栏 5 键对齐（4~8 键）
底栏用绝对定位（宽 54，x=中心-27）：
- 列表页：刷新 x22 / 登录 x79 / 空 x135 / 按键 x190 / 返回 x248
- 登录页：刷新 x22 / 返回 x248
按键 4~8 与屏幕格位一一对应（按位置、不是按数字）。
