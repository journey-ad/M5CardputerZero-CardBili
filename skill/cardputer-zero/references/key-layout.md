# 键盘布局

## 方向与底栏

Cardputer Zero 的 Z / X / C / F 分别对应左 / 下 / 右 / 上。CardBili 同时支持标准方向事件，实际转换见应用的 `src/util.rs`

底栏五项与屏幕下方 4–8 号物理键按位置对应，当前页面决定各项操作。320 像素宽度下，五键中心约为 49 / 106 / 162 / 217 / 275

## 自定义键码

实测系统的 `/usr/share/keymaps/tca8418_keypad_m5stack_keymap.map` 使用以下映射：

| 物理键 | Linux keycode | 符号 |
| --- | --- | --- |
| 1 | 26 | ! |
| 2 | 27 | @ |
| 3 | 39 | # |
| 4 | 40 | $ |
| 5 | 41 | % |
| 6 | 43 | ^ |
| 7 | 51 | & |
| 8 | 52 | * |
| 9 | 53 | ( |
| 0 | 94 | ) |

Linux aarch64 的 `input_event` 通常为 24 字节：timeval、type、code、value；EV_KEY 的 value 0 / 1 / 2 表示松开 / 按下 / 重复。按当前 ABI 解析，并保留松开事件供长按逻辑使用

变更映射前在设备读取事件并逐键确认。桌面预览支持脚本按键；实体键码与长按手感使用真机验证。向 uinput 注入事件只有在应用实际读取该输入节点时才会被接收
